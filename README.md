# Nihongo szótanuló – frissítésjelző

Ebből a `version.json`-ból tudja a Nihongo szótanuló Android-app, hogy van-e újabb verzió.
Az APK a Google Drive-on van (`apkId` = a Drive-fájl azonosítója); a forráskód privát repóban.

Új kiadásnál: `versionCode` (mindig nagyobb), `versionName`, `apkId`, `sha256`, `size`, `notes`.
